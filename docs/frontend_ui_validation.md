# 前端浏览器核查记录

2026-10-03 使用已安装的 Playwright 和 Chromium，在本地 Flask 服务上实际操作。

## 已修复

- 公共牌和自己的手牌在桌面使用 72×102px，手机自己的手牌为 52×74px。点数、花色使用更大的文本标识。
- 1200px 以下采用纵向布局，牌桌保留最低高度；开始新局时同时重置窗口和主内容区的滚动位置。
- 手机 4–9 人桌使用左右分列座位和 3+2 公共牌。7–9 人进行中只突出人类和当前行动者的暗牌，摊牌后恢复全部牌。
- 行动流放在牌桌下方，桌面分成两列，避免覆盖座位。公共牌退出动画脱离文档流，避免切换时暂时撑宽牌桌。
- 行动区保留桌面 220px、手机 264px 的最低高度，避免轮到玩家时新增滑块和赔率信息造成牌桌跳动。
- 手机结算行按玩家、五张最佳牌、描述纵向排列；回放公共牌和玩家信息可换行。
- PL/FL 的合法上限仅在等于全部可用筹码时显示“全下”，其他情况显示“上限”。比例加注补齐跟注金额，并按跟注后的底池计算。

## 核查范围

- 实际对局：NL 的 6、9 人桌；NL、PL、FL 的 2 人桌。
- 实际点击与键盘：开始对局、弃牌、比例下注、P 键、结算、查看本手回放、播放/暂停、2 倍速、Home/End、结束游戏。
- 页面快照边界检查：360、650、768、1000、1201、1440px × 2–9 人 × 河牌/摊牌，共 96 个状态。检查座位之间、座位与公共牌、座位与行动流的覆盖及牌面横向越界。
- 声音和触感在新浏览器上下文中默认关闭；减少动效通过浏览器媒体偏好另行检查。
- 自动检查：前端 5 个下注尺寸用例、TypeScript 类型检查、生产构建；后端 403 个测试；1000 手筹码守恒门禁通过。

界面核查使用桌面 Chromium 的移动视口。真实手机触感、语音和真实 LLM 服务商不属于本次浏览器验证范围。
